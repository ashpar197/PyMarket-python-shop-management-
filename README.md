# 🛒 PyMarket - Python Shop Management System

A beginner-friendly shop management system built with **Python** and **Object-Oriented Programming (OOP)**.

## 📌 Features

- View available products
- Add products to the shopping cart
- Increase quantity of an existing cart item
- Remove products from the cart
- Return removed items to shop inventory
- Check available stock
- Calculate the total bill
- Handle invalid quantity input

## 🧠 Concepts Used

- Classes and Objects
- Object-Oriented Programming (OOP)
- Lists
- Loops
- Conditional statements
- Exception handling
- Methods
- Object interaction

## 🏗️ Classes

### `Product`
Stores product information such as:
- Product name
- Price
- Quantity

### `Customer`
Handles:
- Customer information
- Shopping cart
- Adding products
- Removing products

### `Shop`
Stores the products and their available quantities.

### `Checkout`
Calculates and displays the customer's total bill.
